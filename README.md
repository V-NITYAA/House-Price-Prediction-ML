# House Price Prediction System (ML Minor Project)

An end-to-end Machine Learning minor project that predicts residential property prices based on area, bedroom, and bathroom counts, featuring an interactive web UI.

---

##  Project Overview
- **Objective:** Automate real estate valuation to reduce manual appraisal bias.
- **Algorithm:** Supervised Linear Regression.
- **Dataset:** Synthetic housing dataset featuring area (sq ft), bedrooms, and bathrooms.
- **Model Accuracy:** R² Score of **0.9826**.
- **Interface:** Single-page web application powered by Gradio.

---

##  Tech Stack & Dependencies
- **Language:** Python 3
- **Data Manipulation:** `pandas`, `numpy`
- **Machine Learning:** `scikit-learn` (`LinearRegression`, `SimpleImputer`, `train_test_split`)
- **Web App / Deployment:** `gradio`
